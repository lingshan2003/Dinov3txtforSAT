# 第一阶段报告研究主线与早期构想取舍

日期：2026-10-08。依据根目录现行研究规划、初始commit bba5c89中的原始规划及当前三seed复现结果整理。本文件是报告叙事建议，不将未做实验改写为已完成贡献，也不将后续假设视为新增训练授权。

## 1. 建议的核心问题

> 在冻结视觉骨干的条件下，应该调整哪些跨模态模块、使用怎样的遥感图文监督，才能提高领域检索并控制迁移代价？

保留原始规划“What Should Be Aligned”的问题意识，把第一阶段范围收敛到原生DINOv3.txt的全局图文检索。
阶段报告可用“面向遥感图文检索的参数高效联合适配与迁移分析”作为工作题目。
这是项目要检验的问题，不等于已经由文献综述确立唯一研究空白；正式背景中的新颖性与论文引用需另行核验原始资料。

## 2. 第一阶段的叙事顺序

### 研究动机

对已有通用图文模型进行遥感适配，目标是利用现有表示和有限训练资源改善检索，不从零预训练视觉或文本基础模型。
研究对象是图文对应关系；视觉表征较强、文本语言流畅或训练loss降低，都不能单独证明遥感跨模态匹配已足够好。
该项目当前证据来自固定数据划分，不将“遥感”扩写成全部地域、传感器或任务上的能力。

### 早期探索与问题收敛

SAT视觉初始化接入通用dino.txt head/text后的结果，包含视觉接口兼容性混杂。
将这部分作为早期诊断：更换视觉骨干并不自动保留原图文接口，现有对照不能识别纯视觉预训练域的净效应。
后续转向原生配套Web组合，以明确起点做参数高效适配；不能将探索过程改写成所有消融都事先预注册的单一实验。
阶段报告简短交代方向调整即可，详细SAT矩阵放后续论文或附录。

### 遥感监督关系与评测

同一caption对应多张有效图片，普通逐行配对容易把已知正例当成负例。
早期一caption一图用于简化问题，随后保留固定train/val caption边界、恢复训练图片，并屏蔽已知同文假负例。
同时保留unique检索作为共同尺度，并增加group-aware多图检索及按caption组均衡统计。
这构成当前方法成立的数据与评价基础；不能把已有屏蔽目标冒充新损失，也不能声称本轮三seed实验单独证明它优于所有替代目标。
当前规范化同文关系是已知正例的一部分，不是完整语义真值；模板、同义文本和不可见属性仍可能影响监督。

### 可识别的方法比较

以原生初始化、adapter-only及adapter＋完整文本LoRA为当前核心比较。
视觉骨干/head冻结，比较在已有adapter上增加文本block及projection低秩更新的效应。
固定数据、训练覆盖、配方和候选池，再做三个配对训练seed，检验同域收益及外部变化。
原生起点、控制组与联合组分别解释“有没有收益”和“文本更新的额外收益”。

### 主要观察与新的问题

unique MR为原生8.63%、adapter-only14.65±0.13%、联合17.78±0.17%；配对增益3.13±0.14pp。
多图按图和按组均衡均有一致增益，三个seed同域双向六项Recall全部提高。
RSICD联合14.14±0.25%高于adapter-only12.22±0.09%，但两者均低于原生14.48%，且R@1和方向指标存在退化。
因此，增加文本更新在本配方中同时提高同域检索并减小外部MR损失；冻结原有模块并不保证最终检索关系保持。
这是行为观察，不等于已解释内部几何机制，也不等于全文本LoRA在所有条件下最优。

## 3. 早期构想的取舍

| 原始构想 | 当前角色 | 适合怎样写 |
| --- | --- | --- |
| 冻结视觉骨干、低成本领域对齐 | 第一阶段主线 | 已有完整训练与三seed配对证据 |
| 视觉adapter与文本有限更新 | 第一阶段核心对照 | 联合在adapter存在时的增量已验证；两侧是否必要尚未验证 |
| Web/SAT视觉域×语言域矩阵 | 早期探索与辅助诊断 | 保留结果，明确迁移head混杂，不宣称净视觉域因果效应 |
| 文本自然描述、结构化和层级粒度 | 后续最值得保留的研究轴之一 | 同图、同split、同事实来源对照；格式与新增信息分开检验 |
| 多图同文与多正例关系 | 已实现的数据/评测基础，部分目标探索 | 屏蔽假负例与均匀多正例目标分别命名；不声称所有同义正例已解决 |
| 数据规模与效率 | 已有探索，尚未形成尺度规律 | 后续用嵌套图片子集、受控曝光预算，区分更多实例与更多训练 |
| 跨数据集保持和失败分析 | 贯穿主线 | 同域提升与外部退化分别报告，RSICD为开发外部验证 |
| Zero-shot分类 | 辅助评价候选 | 独立于检索定义；历史已观察数据不包装成未触碰测试 |
| 全局与局部/metadata辅助对齐 | 可选远期扩展 | 当前无独立局部实验；热力图不能替代定位或分割评价 |
| 从头重训head或完整文本塔 | 接口诊断或后续容量对照 | 不作为当前成果所必需的预训练路线 |
| 丰富外部模型/数据集清单 | 相关工作与候选储备 | 正式比较前验证来源重叠、协议、资产与文献；不变成必须执行的长清单 |

旧规划将梯度累计与候选扩张并列的说法不宜复用：梯度累计扩大优化器曝光batch，不扩大每次对比softmax的候选集。
旧README“全文本冻结、仅adapter为主线”已更新为当前联合方案。

## 4. 当前能写成什么贡献

第一阶段定位为可复现的实证研究和可靠适配基线：

1. 建立保留多图实例、明确同文正例关系的训练及检索流程，记录冻结边界、训练覆盖与恢复状态。
2. 在匹配预算的三个训练seed上，识别加入文本LoRA相对adapter-only的稳定增量。
3. 分析同域收益与外部方向指标的权衡，报告该方法何处有效、何处仍有损失。

adapter、LoRA、假负例屏蔽都不是本项目已证明的新算法。
三个seed足以支持当前范围内的重复性观察，不足以自动宣称SOTA、统计显著性、地理泛化或模块机制已查明。

## 5. 最自然的后续延伸

### 先回答两侧是否必要

| 视觉adapter更新 | 文本LoRA更新 | 状态 |
| --- | --- | --- |
| 无 | 无 | 原生基线已有 |
| 有 | 无 | 三seed已完成 |
| 无 | 有 | 原生Web当前同预算尚缺 |
| 有 | 有 | 三seed已完成 |

当前可以说“在adapter存在时，文本LoRA带来额外收益”。
若要说“双方缺一不可”或主张协同交互效应，需要补文本LoRA-only并比较四条件，而不是仅依据联合超过adapter-only。
Transformer block与projection贡献也需额外分解；SAT旧模块实验不直接替代原生Web对照。

### 再研究对齐什么样的文本

文本粒度是原计划中与现有检索主线衔接较好的延伸。
当前短caption、同事实的自然改写和结构化表达，应保持图片、split和事实来源不变；要增加可见细节，则作为新增语义信息的独立研究。
记录token长度、可见性和信息来源；不能把更长或更流畅自动视作更准确的监督，也不能用LLM生成的未核实属性当真值。
如果只扩展一个方向，应根据模块机制与文本语义二者中最希望回答的问题选择，而非同时推进所有原始构想。

局部对齐需另立监督和局部评价，当前全局视觉adapter并无显式patch监督。文本更新可能改变patch-text分数，但仅有热力图变化不构成局部学习能力证据。

## 6. 第一份报告的内容配置

摘要与引言围绕冻结骨干的遥感检索适配问题；SAT诊断用简短段落解释问题收敛。
方法说明两种参数范围、同文关系屏蔽、完整图片覆盖和检索正例定义。
主实验表用原生、adapter-only、联合三seed结果，配对差值与资源成本支撑比较。
结论写“稳定同域收益与较小外部MR损失”；展望写两侧必要性、文本表达或迁移保持，将局部对齐放可选扩展。
不把未执行实验、未观察的SOTA比较或领域内文献空白预先列作贡献。
